# MisCuentas

Aplicación de cuentas, movimientos, apartados e invitaciones.

## Backend actual
La versión activa de esta carpeta usa Neon Auth y Neon Data API. La configuración está en `neon-config.js`.

## Migración y respaldos
Los archivos de la carpeta `supabase/` y `supabase-config.js` se conservan como respaldo histórico de la migración. No son utilizados por `index.html`.

No borrar el proyecto o los datos antiguos hasta terminar las pruebas funcionales de Neon.
